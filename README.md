# Идеальное рабочее место

Небольшая браузерная игра, где ты выполняешь простые задания (чтение статьи, вайб‑кодинг, ревью заметок), получаешь **фокус** и **опыт**, а затем открываешь улучшения для своего рабочего места.

## Что нового

- Добавлена **пиксельная сцена** на `canvas`.
- Все предметы рисуются из локальной библиотеки pixel-art спрайтов (`SPRITES` + `PALETTE`).
- При покупке улучшений сцена обновляется и визуально показывает развитие студии.

## Как запустить

Открой `index.html` в браузере.

## Игровой цикл

1. Выполняй задания из блока **Задания**.
2. Получай фокус и опыт.
3. Повышай уровень.
4. Покупай улучшения в **Магазине улучшений**.
5. Наблюдай, как пиксельная студия становится лучше.
